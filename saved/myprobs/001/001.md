# statement

長さ $N$ の非負整数列 $A,B$ と、$0$ か $1$ からなる数列 $U$ が与えられます。\
$1$ 以上 $N$ 以下の整数から相異なる $K$ 個の整数を選び、任意の順番で並べた数列 $P$ について、**スコア**を $\sum_{i=1}^{K-1}\max\big(A_{P_i}\ ,B_{P_i}×U_{P_{i+1}}\big)$ と定めます。\
達成可能なスコアの最大値を求めてください。

# input

入力は以下の形式で標準入力から与えられます。

```
$N\enspace K$
$A_1\enspace A_2\enspace \dots\enspace A_N$
$B_1\enspace B_2\enspace \dots\enspace B_N$
$U_1\enspace U_2\enspace \dots\enspace U_N$
```

- $2 \le K \le N \le 500$
- $1 \le A_i, B_i \le 2×10^5$
- $U_i \in \\{0, 1\\}$
- 入力は全て整数

# output

答えを整数として出力してください。

# sample

```sample-input
7 3
3 2 1 2 1 1 1
5 5 6 7 8 9 10
0 0 1 0 1 0 0
```

```sample-output
18
```

$P=\\{7, 5, 3\\}$ を選んだときスコアは $18$ となり、これが達成可能な最大値です。
