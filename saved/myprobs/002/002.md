# statement

> ＿人人人人＿\
> ＞ 　`ovo` 　＜\
> ￣Y^Y^Y^Y￣

ある文字列 $T$ が以下の条件をすべて満たすとき、$T$ を**スマイルな文字列**と呼ぶことにします。

- $|T| = 3$ である
- $2$ 文字目が`v`、`u`、`w`のいずれかである
- $1$ 文字目と $3$ 文字目が同じである

長さ $N$ の文字列 $S$ が与えられます。$S$ の部分文字列であって、スマイルな文字列であるものの個数を出力してください。

# input

入力は以下の形式で標準入力から与えられます。

```
$N$
$S$
```

- $3 \le N \le 100$
- $S$ は英小文字からなる長さ $N$ の文字列

# output

答えを整数で出力してください。

# sample

```sample-input
6
ovoxwx
```

```sample-output
2
```

条件を満たす部分文字列は`ovo`、`xwx`の2つです。


```sample-input
14
wwwvwwvwwvwvvv
```

```sample-output
4
```


```sample-input
3
wow
```

```sample-output
0
```


```sample-input
18
なんかかく
```

```sample-output
0
```
