# 気づき

- プレイ人数をM、レベル上限をUとする
- まずM=2とそれ以外は完全に別ゲー
- 全般に通じるコツ
  - 相手の領地を分断することで、相手の「興味のある範囲」を減らすことができる

## M=2

- 2人ゲームにおける戦略
- テストケース生成においてMがランダム生成なことを考えると詰める優先度は低め

### U=1

- 相手の領地を塗り替えしまくるだけ
- たまにεを引いて無駄な行動をするとき（隙ターン）があるので、その隙に散らばった相手のマスを回収する
- 続けていれば最終的に相手の領地は2マス以下になるはず
  - 相手のεが低かったり、初期位置が遠かったりすると散らばったマスを回収しきれないことはある
- 相手のマスを複数踏める場合の選び方について
  - M=2, U=1で思考に時間を使うのはここのはず
  - 自分の領地が分断されそうだと行動範囲が狭まるので、分断されてまずいなら接続/補強を優先する
  - 相手にはなるべく未占領マスを踏んでもらった方が評価値の総和が増えて嬉しいので、なるべく内地（自分の領地の近く）の回収を優先する
- 逆に、相手が残り1マス（駒のあるマス）しか残っていないなら、まあ踏める未占領のうち評価値の高いやつとかを適当に踏む

### U>=2

- 相手を角やLv.2の領地で囲った隅に追い詰める
  - 角に追い詰められるならそれを狙ったほうがいい
  - 逃がさないことを第一に考える
    - 分断したときに広いほうに逃げられてしまうと最悪
  - Lv.1の相手の領地が取れる状態であればよく考えて取る
    - 分断して変なことにならないならしていい
    - 相手の領地が狭まるだけで分断しないならもう遠慮なく
  - waとwcが高いと若干話が変わってくる節あり
    - 角に追い込みづらい、そもそも囲えない
    - M=2, U=1みたくLv.1を追いかける戦法に近くなりそう
- 相手を追い詰めたら
  - 壁を維持しながら、追い詰めた部分以外の散らばった相手の領地を取り返していく（分母を減らす）
- 散らばった領地を取り返した/そもそもない場合
  - まだ相手の領地にLv.1とかが残っていて、相手の領地が狭くできそうならチャレンジ
  - 相手のεが低くて無理そうな感じならあきらめる
- あとは自分の領地や未占領の領地のレベルを上げて絶対スコアの底上げ
